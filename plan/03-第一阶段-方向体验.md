## 第 7 天 · 10/28 周三：实验 C · 假 Agent

> 目的：不理解 API、不花钱，先手写一遍 Agent 的核心循环。

### 核心概念

Agent 不是魔法，它就是一个循环：

```text
用户输入 → 模型判断 → 要不要调用工具？
                    ├─ 要 → 执行工具 → 把结果给模型 → 继续判断
                    └─ 不要 → 直接回答
```

### 任务（100 分钟）

新建 `taste/agent/mock_agent.py`：

```python
def fake_llm(prompt):
    """假模型：不联网，只按关键词返回固定结果。"""
    if "天气" in prompt:
        return "CALL_TOOL: weather"
    if "时间" in prompt:
        return "CALL_TOOL: time"
    return f"ANSWER: 我不太懂「{prompt}」，但我在学习。"

def weather_tool():
    return "晴，25 度"

def time_tool():
    return "现在是学习时间"

def run_agent(user_input):
    reply = fake_llm(user_input)

    if reply.startswith("CALL_TOOL:"):
        tool_name = reply.split(":")[1].strip()
        if tool_name == "weather":
            result = weather_tool()
        elif tool_name == "time":
            result = time_tool()
        else:
            result = "没有这个工具"
        print(f"[调用工具 {tool_name}] 结果：{result}")
        # 把工具结果再交给模型
        final = fake_llm(f"工具结果是 {result}，请回答用户")
        print(final)
    else:
        print(reply)

if __name__ == "__main__":
    while True:
        text = input("你：")
        if text == "退出":
            break
        run_agent(text)
```

要求：

- 自己敲一遍
- 试三个输入：`今天天气怎么样`、`现在几点`、`你好`
- 加一个新工具 `calculator`，能算 `1+2`

### 20 分钟：记录感受

- 你更想研究「怎么让模型更聪明」，还是「怎么把工具接进来」？
