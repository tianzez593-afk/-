## 二、LeetCode 计划

### 题量目标

| 类型 | 数量 | 说明 |
| --- | --- | --- |
| easy | 60 | 熟练，看到题能立刻有思路 |
| medium | 40 | 高频题型，能独立写出 |
| hard | 0–5 | 不强制，时间不够就放弃 |

### 刷题顺序（按题型，不按题号）

1. 数组 / 字符串 / 哈希
2. 双指针 / 滑动窗口
3. 栈 / 队列
4. 链表
5. 二分查找
6. 二叉树
7. 图 / BFS / DFS（基础）
8. 动态规划（基础）

### 每周节奏

- 周一到周五：每天 1–2 题
- 周六：重做本周错题
- 周日：重做 1 周前、3 周前的错题

### 错题规则

- 做不出来：最多想 20 分钟，然后看题解
- 看完题解：关掉，自己重写一遍
- 第二天：再做一遍
- 第七天：再做一遍
- 仍然不会：标记为「重点错题」，写清卡在哪一步

### 题解模板

```markdown
## 题目：Two Sum

- 思路：
- 时间复杂度：
- 空间复杂度：
- 易错点：
- 关键代码：
```

## 三、CS 面试题

### 网络（必须会）

- 输入网址到页面出现，发生了什么？
- TCP 三次握手 / 四次挥手
- TCP 和 UDP 的区别
- HTTP 和 HTTPS 的区别
- GET 和 POST 的区别
- 常见状态码：200 / 301 / 302 / 400 / 401 / 403 / 404 / 500
- DNS 解析过程
- Cookie / Session / Token 的区别

### 操作系统（必须会）

- 进程和线程的区别
- 线程之间怎么通信
- 什么是死锁？四个必要条件？
- 虚拟内存是什么？
- 分页和分段（了解）
- 用户态和内核态（了解）

### 数据库（必须会）

- 索引是什么？为什么能加速？
- 什么时候索引会失效？
- 事务的 ACID
- 脏读、不可重复读、幻读
- 内连接、左连接、右连接的区别
- 慢查询怎么排查？

### Python（必须会）

- 列表和元组的区别
- 深拷贝和浅拷贝
- `*args` 和 `**kwargs`
- 装饰器是什么
- 生成器和迭代器的区别
- GIL 是什么
- 异常处理

### 项目（必须会）

准备好用 3–5 分钟讲清楚：

1. 项目解决什么问题
2. 技术栈和架构
3. 你负责的部分
4. 遇到的最大困难，怎么解决
5. 如果重做，会改什么

## 四、简历

### 一页纸，四个部分

```text
基本信息
教育背景
项目经历（2 个）
技能清单
```

### 项目描述模板

```text
项目名称：AI 学习助手
时间：2026.12 – 2027.02
技术栈：Python、Django、MySQL、Redis、MongoDB、大模型 API

- 做了什么：基于 Django 实现目标、任务、打卡管理
- 难点：Agent 如何读取真实数据并生成建议
- 方案：设计工具调用层，Agent 通过工具查询任务和打卡
- 结果：完成 X 个功能，接口平均响应 X ms，测试覆盖核心逻辑
```

### 写简历的规则

- 不写「精通」，写「熟悉 / 了解 / 使用过」
- 每个项目至少有一个数字：表数量、接口数、测试数、响应时间
- 不写课程作业，除非它真的能展示能力
- 简历不超过一页

## 九、常见心态问题

| 想法 | 实际情况 |
| --- | --- |
| 「我题还没刷完，不能投」 | 永远刷不完，达到 60% 就可以投 |
| 「我项目太简单」 | 能讲清楚、能跑起来，就比大多数强 |
| 「投了没回复」 | 正常，投递是概率游戏，扩大数量 |
| 「面试挂了很丢人」 | 每次面试都是一次免费模拟，复盘就有收获 |
| 「别人都比我强」 | 你只需要比昨天的自己强，拿到一个 offer 就够 |
