## 先记住这几件事

1. 进程是「正在运行的程序」，有独立内存。
2. 线程是进程里的执行单元，同一进程的线程共享内存。
3. 线程切换比进程切换便宜。
4. 多线程共享数据会出竞态条件，需要锁。
5. 死锁需要同时满足四个条件，打破一个就能避免。

---

## 一、进程 vs 线程

| 维度 | 进程 | 线程 |
| --- | --- | --- |
| 定义 | 运行中的程序实例 | 进程内的执行单元 |
| 内存 | 独立地址空间 | 共享进程内存 |
| 切换开销 | 大 | 小 |
| 通信 | 管道、消息队列、共享内存 | 直接读写共享变量 |
| 崩溃影响 | 通常不影响其他进程 | 可能拖垮整个进程 |

### 类比

- 进程 = 一栋房子，有独立的房间和水电
- 线程 = 房子里的几个人，共用客厅和厨房

### 什么时候用多进程 / 多线程

| 场景 | 选择 |
| --- | --- |
| CPU 密集（计算） | 多进程（Python 有 GIL，多线程不能真并行） |
| I/O 密集（网络、文件） | 多线程 / 异步 |
| 需要隔离 | 多进程 |

## 三、内存管理

### 虚拟内存

每个进程都以为自己有一整块连续内存，实际上由操作系统映射到物理内存。

好处：

- 进程隔离
- 可以使用比物理内存更大的地址空间
- 方便内存保护

### 分页

- 把内存切成固定大小的页
- 虚拟页 → 物理页的映射表叫页表
- 缺页中断：访问的页不在内存，从磁盘加载

## 四、锁、竞态、死锁

### 竞态条件

两个线程同时修改一个变量，结果取决于执行顺序。

```python
import threading

count = 0

def add():
    global count
    for _ in range(100000):
        count += 1

t1 = threading.Thread(target=add)
t2 = threading.Thread(target=add)
t1.start(); t2.start()
t1.join(); t2.join()

print(count)  # 通常小于 200000
```

### 加锁

```python
import threading

count = 0
lock = threading.Lock()

def add():
    global count
    for _ in range(100000):
        with lock:
            count += 1

t1 = threading.Thread(target=add)
t2 = threading.Thread(target=add)
t1.start(); t2.start()
t1.join(); t2.join()

print(count)  # 200000
```

### 死锁的四个条件

1. 互斥：资源一次只能被一个线程占用
2. 持有并等待：拿着一个资源等另一个
3. 不可剥夺：资源不能被强行抢走
4. 循环等待：A 等 B，B 等 A

打破任意一个，就不会死锁。

## 五、用户态和内核态（了解）

- 用户态：普通程序运行，权限受限
- 内核态：操作系统内核运行，权限最高
- 系统调用：用户态请求内核态提供服务（读文件、网络、创建进程）

为什么要分：安全。普通程序不能直接操作硬件。

## 七、Python 相关

### GIL

Python 的全局解释器锁：同一时刻只有一个线程执行 Python 字节码。

影响：

- CPU 密集任务多线程不能真并行
- I/O 密集任务多线程仍然有效
- 想利用多核：多进程

### 多线程示例

```python
import threading

def worker(name):
    print(f"{name} 开始")
    print(f"{name} 结束")

threads = [threading.Thread(target=worker, args=(f"T{i}",)) for i in range(3)]
for t in threads:
    t.start()
for t in threads:
    t.join()
```

### 多进程示例

```python
from multiprocessing import Process

def worker(name):
    print(f"{name} 在子进程")

if __name__ == "__main__":
    p = Process(target=worker, args=("P1",))
    p.start()
    p.join()
```
