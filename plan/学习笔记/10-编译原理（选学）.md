# 编译原理（选学）

> 对应图片里的「编译」。
> 目标：理解「代码怎么变成可执行的东西」，不要求手写完整编译器。
> **建议：实习后再深入；准备期只需要知道基本概念。**

---

## 先记住这几件事

1. 编译大致分：词法分析 → 语法分析 → 语义分析 → 中间代码 → 优化 → 目标代码。
2. 词法分析把字符切成 token。
3. 语法分析把 token 组成 AST（抽象语法树）。
4. 解释器直接执行 AST；编译器生成目标代码。
5. 你写的 AI 代码工具、SQL 解析、JSON 解析，背后都有这些思想。

---

## 一、为什么学

- 面试加分：能解释「代码怎么运行」
- 理解报错：`SyntaxError` 就是语法分析阶段失败
- 理解工具：ESLint、Prettier、SQL 解析、AST 转换
- 理解 Agent：很多代码 Agent 会解析/生成 AST

> 对后端/Agent 实习来说，编译原理不是必须，属于加分项。

---

## 二、四个阶段

```text
源代码
  → 词法分析（Lexer）→ token 流
  → 语法分析（Parser）→ AST
  → 语义分析 → 带类型信息的 AST
  → 解释执行 / 生成目标代码
```

### 1. 词法分析

输入：`1 + 2 * 3`

输出 token：

```text
NUMBER(1)
PLUS(+)
NUMBER(2)
STAR(*)
NUMBER(3)
EOF
```

### 2. 语法分析

把 token 组成树：

```text
      +
     / \
    1   *
       / \
      2   3
```

这棵树就是 AST。

### 3. 语义分析

检查：

- 变量是否定义
- 类型是否匹配
- 函数参数数量对不对

### 4. 解释 / 编译

- 解释器：遍历 AST，直接算结果
- 编译器：把 AST 转成机器码/字节码

## 三、最小例子：四则运算解释器

### 词法分析

```python
def tokenize(text):
    tokens = []
    i = 0
    while i < len(text):
        ch = text[i]
        if ch.isspace():
            i += 1
        elif ch.isdigit():
            num = ch
            i += 1
            while i < len(text) and text[i].isdigit():
                num += text[i]
                i += 1
            tokens.append(("NUMBER", int(num)))
        elif ch in "+-*/()":
            tokens.append((ch, ch))
            i += 1
        else:
            raise ValueError(f"不认识的字符：{ch}")
    tokens.append(("EOF", None))
    return tokens
```

### 语法分析（简化）

```python
class Parser:
    def __init__(self, tokens):
        self.tokens = tokens
        self.pos = 0

    def peek(self):
        return self.tokens[self.pos]

    def eat(self, kind):
        token = self.peek()
        if token[0] != kind:
            raise SyntaxError(f"期望 {kind}，实际 {token[0]}")
        self.pos += 1
        return token

    def parse(self):
        return self.expr()

    def expr(self):
        node = self.term()
        while self.peek()[0] in ("+", "-"):
            op = self.peek()[0]
            self.pos += 1
            right = self.term()
            node = (op, node, right)
        return node

    def term(self):
        node = self.factor()
        while self.peek()[0] in ("*", "/"):
            op = self.peek()[0]
            self.pos += 1
            right = self.factor()
            node = (op, node, right)
        return node

    def factor(self):
        kind, value = self.peek()
        if kind == "NUMBER":
            self.pos += 1
            return value
        if kind == "(":
            self.pos += 1
            node = self.expr()
            self.eat(")")
            return node
        raise SyntaxError(f"意外的 token：{kind}")
```

### 求值

```python
def evaluate(node):
    if isinstance(node, int):
        return node

    op, left, right = node
    a = evaluate(left)
    b = evaluate(right)

    if op == "+":
        return a + b
    if op == "-":
        return a - b
    if op == "*":
        return a * b
    if op == "/":
        return a / b
    raise ValueError(f"未知运算符：{op}")
```

### 串起来

```python
text = "1 + 2 * 3"
tokens = tokenize(text)
ast = Parser(tokens).parse()
print(ast)          # ('+', 1, ('*', 2, 3))
print(evaluate(ast))  # 7
```

> 这个例子只有 100 行左右，但已经包含词法、语法、AST、求值。
> 跑通它，你就理解了编译原理的骨架。

## 四、学习顺序（实习后）

1. 词法分析：正则、token
2. 语法分析：递归下降、AST
3. 语义分析：符号表、类型检查
4. 解释器：遍历 AST
5. 字节码 / 虚拟机（选学）
6. 优化（选学）
