## 三、优先级

| 优先级 | 内容 | 时间占比（建议） |
| --- | --- | --- |
| 🔴 最高 | Python、Git、数据库、代码阅读、Agent 项目 | 50% |
| 🟠 高 | LeetCode | 30% |
| 🟡 中 | 操作系统、计算机网络 | 15% |
| ⚪ 后置 | 编译原理 | 5% 或实习后 |

**不要平均分配。** 实习第一天用的是 Python、Git、数据库、读代码；面试才用算法和 CS 基础。

---

## 四、每周节奏（2 小时/天 × 6 天）

| 时间 | 做什么 |
| --- | --- |
| 周一 | 看本周主题，写 3 个目标 |
| 周二–周五 | 每天 2 小时：30 分钟笔记 + 30 分钟 LeetCode + 50 分钟写代码 + 10 分钟日志 |
| 周六 | 做本周小项目 / 补进度 |
| 周日 | 复盘 + 填能力自评 + 发周报 |

每周产出至少一个：

- 一个能运行的脚本/页面
- 一篇 300 字以上的笔记
- 5 道题的题解
- 一张调用关系图

## 六、每周检查问题

每周日问自己：

1. 这周写了多少行代码？
2. 这周有没有一个能拿给别人看的产出？
3. LeetCode 做了几道？错题重做了吗？
4. 有没有一个「以前不懂、现在能讲清楚」的概念？
5. 下周最重要的一件事是什么？

---

## 七、进度落后怎么办

| 情况 | 调整 |
| --- | --- |
| 某周只学了 3 天 | 不补时长，直接把本周主题顺延 3 天 |
| 课程看不完 | 只看核心章节，跳过扩展 |
| 项目卡住 | 砍功能，先做最小可运行版本 |
| 期末考试 | 停新课，每天只保 30 分钟 LeetCode |
| 方向想换 | 只改阶段 2 之后的内容，Python/Git/算法不重来 |
