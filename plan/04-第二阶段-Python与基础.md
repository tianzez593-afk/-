## 二、第 1 周：Python 核心语法

### 学什么

- 变量、数字、字符串、布尔值
- `if / elif / else`
- `for`、`while`
- `list`、`tuple`、`dict`、`set`
- 索引、切片、常用方法

### 每天 2 小时怎么分

- 30 分钟：看 `学习笔记/01-Python基础.md`
- 30 分钟：LeetCode 1 道 easy
- 50 分钟：写小练习
- 10 分钟：日志

### 本周练习（每天至少 2 个）

1. 输入两个数，输出和、差、积、商
2. 判断一个数是奇数还是偶数
3. 打印 1–100 中所有能被 3 整除的数
4. 输入 5 个数，求平均值
5. 把一个列表倒序打印
6. 统计一句话里有多少个元音字母
7. 把两个列表合并并去重
8. 找出列表中的最大值和最小值（不用 `max/min`）
9. 判断一个字符串是不是回文
10. 用字典统计一句话里每个字出现的次数
11. 打印九九乘法表
12. 猜数字游戏（加「只能猜 5 次」）
13. 判断闰年
14. 打印斐波那契数列前 20 项
15. 把摄氏度转华氏度，支持批量输入

### 本周产出

一个命令行小工具，至少包含：

- 一个菜单
- 至少 3 个功能
- 输入错误时不崩溃

## 三、第 2 周：函数、集合、文件、异常

### 学什么

- `def`、参数、默认参数、`return`
- 作用域
- `list / dict / set` 的常用操作
- `with open()` 读写文件
- `try / except / finally`
- `json` 读写

### 本周练习

1. 把第 1 周的工具拆成函数
2. 写 `read_file(path)`，文件不存在时返回 `None`
3. 读一个 CSV，算每列平均值
4. 读一个 JSON，修改一个字段再写回
5. 统计一个文本文件的词频，输出前 10
6. 写 `safe_int(text)`，转换失败返回 `None`
7. 写一个函数，接收任意个数字，返回平均值
8. 用 `set` 找出两个列表的共同元素
9. 用 `dict` 实现一个简单的电话簿（增删查）
10. 写一个日志函数，把每次操作追加到 `log.txt`

### 本周产出

单词统计升级版：

- 支持命令行参数：`python word_count.py sample.txt`
- 支持 `--top 10`
- 文件不存在时给出友好提示
- 有一个 `if __name__ == "__main__":` 入口

## 四、第 3 周：类、模块、虚拟环境、pip

### 学什么

- `class`、`__init__`、实例属性、方法
- 继承（了解即可）
- `import`、模块、包
- `venv` 虚拟环境
- `pip install`、`requirements.txt`
- 类型注解（`def f(x: int) -> str:`）

### 本周任务

1. 把「电话簿」改成一个 `PhoneBook` 类
2. 把项目拆成至少 3 个文件：
   - `main.py`
   - `storage.py`
   - `models.py`
3. 建虚拟环境：

```cmd
python -m venv .venv
.venv\Scripts\activate.bat
pip install requests
pip freeze > requirements.txt
```

4. 用 `requests` 调一个公开 API（比如天气/笑话），把结果打印出来
5. 给函数加类型注解

### 本周产出

- 一个多文件项目
- `requirements.txt`
- README 里写清楚怎么安装、怎么运行

## 五、第 4 周：Git 工作流 + 测试入门

### 学什么

- `clone / status / diff / log`
- `branch / switch / merge`
- `remote / push / pull`
- `restore / revert / reset`
- `.gitignore`
- 单元测试：`assert`、`unittest` 或 `pytest`

### 本周任务

1. 给项目建 `.gitignore`（忽略 `.venv/`、`__pycache__/`）
2. 新建分支 `feature/tests`，写 3 个测试
3. 合并回 `main`
4. 故意制造一次冲突，手动解决
5. 用 `git revert` 撤销一次错误提交
6. 把项目推到 GitHub，README 加运行截图（可选）

### 本周产出

- 一个带测试的 GitHub 仓库
- `git-notes.md`：记录冲突怎么解决、revert 和 reset 的区别
