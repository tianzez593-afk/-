# 能力自评与复盘

> 每两周填一次。不要凭感觉，用「最近做过什么」来打分。

---

## 一、0–5 分标准

| 分数 | 含义 | 判断依据 |
| --- | --- | --- |
| 0 | 完全不会 | 没接触过 |
| 1 | 看过 / 知道名字 | 能说几个词，但写不出来 |
| 2 | 能照抄 | 跟着教程能做，离开教程就卡 |
| 3 | 能独立做 | 不看书能完成常见任务 |
| 4 | 能讲清楚 | 能解释原理、能排错、能教别人 |
| 5 | 能优化 / 做决策 | 能比较方案、做取舍、处理边界情况 |

## 五、判断「真的进步了」的 5 个信号

1. 以前要查半天的语法，现在能直接写
2. 看到报错不再慌，知道先看最后一行
3. 能用自己的话把一个概念讲给外行
4. 做过的题，隔一周还能独立做出来
5. 项目里敢删掉 AI 生成的代码，自己重写

如果一条都没有，说明输入太多、动手太少。

## 六、每两周检查：是不是在「假努力」

| 假努力 | 真学习 |
| --- | --- |
| 收藏了 20 门课 | 学完 1 门，做了笔记 |
| 看了 3 小时视频 | 写了 50 行代码 |
| 抄了一遍题解 | 关掉题解重写一遍 |
| 让 AI 生成整个项目 | 自己写核心逻辑，AI 只解释 |
| 计划排得很满 | 每周完成 3 件最重要的事 |
