## 提交规则

每个练习：

1. 在仓库里建对应文件夹，例如 `day01/`
2. 代码文件命名清楚，例如 `guess_number.py`
3. 文件顶部写一行注释说明用途
4. 提交信息格式：`day01: 完成猜数字游戏`
5. 推送到 GitHub

---

## 验收规则

一个练习算完成，必须满足：

- [ ] 代码能运行
- [ ] 自己能解释每一行
- [ ] 至少处理一种错误输入
- [ ] 提交到 GitHub
- [ ] 写了 3 行总结（学到什么、卡在哪、下次怎么改）
